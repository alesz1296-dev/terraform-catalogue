Static site delivery path

A common beginner-friendly AWS pattern is to store static files in S3 and serve them through CloudFront. The S3 bucket should stay private, with CloudFront as the public entry point.

Cost and safety

Build like the bill is real.

Static hosting is low cost, but good habits start here: budgets, tagging, private buckets, least-privilege IAM, and cleanup notes.

  • Create an AWS Budget alert before deploying.
  • Keep the S3 bucket private and use CloudFront OAC.
  • Never commit access keys or Terraform state with secrets.
  • Document deploy and destroy steps in every project.
